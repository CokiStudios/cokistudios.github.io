# CSMS Android — Standalone Native Kotlin & Jetpack Compose Client

**CSMS (Coki Messaging Service)** es una aplicación 100% nativa desarrollada en **Kotlin** y **Jetpack Compose** para dispositivos Android.

---

## Características Principales

1. **Sincronización Supabase REST**: Conectado directamente a las tablas `chat_rooms` y `chat_messages`.
2. **Diseño Liquid Glass UI**: Modo oscuro estricto (`#06090F` / `#0F172A`), pastillas de chat con degradados luminosos y barras de herramientas translúcidas.
3. **Desarrollo Nativo**: Compila directamente en **Android Studio** utilizando Gradle Kotlin DSL.

---

## Cómo Ejecutar en Android Studio

1. Abre **Android Studio**.
2. Selecciona **Open** y navega hasta la carpeta `CSMS.Android`.
3. Espera a que Gradle termine la sincronización de dependencias (`Sync Project with Gradle Files`).
4. Selecciona tu emulador o dispositivo físico y presiona **Run 'app'** (`Shift + F10`).
