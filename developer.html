Arquitectura Universal de Integración CS ID Connect v2.0
RFC 6749 • RFC 7636 PKCE S256

CS ID Connect proporciona identidad federada respaldada por hardware en navegadores y aplicaciones nativas. Todos los intercambios de credenciales se procesan sin exponer contraseñas a clientes externos. Los tokens son cifrados usando JWE (AES-256-GCM) y compatibles con Apple Secure Enclave y Android StrongBox.

Opción A: Web Component Oficial (1 línea de código)

<!-- Importa el SDK desde el CDN de Coki Studios -->
<script type="module" src="https://cdn.cokistudios.com/csid-connect.js"></script>

<!-- Agrega el botón oficial a tu interfaz HTML -->
<csid-connect-button client-id="tu_client_id" theme="glass" shape="pill" mode="popup"></csid-connect-button>

<!-- Escucha el evento de autenticación exitosa -->
<script>
  document.querySelector('csid-connect-button').addEventListener('success', (e) => {
    console.log('Usuario autenticado:', e.detail.user);
    console.log('Token de acceso:', e.detail.accessToken);
  });
</script>

Opción B: SDK Modular JavaScript & One-Tap

// Inicializar CS ID Connect con soporte One-Tap
import { CSIDConnect } from 'https://cdn.cokistudios.com/csid-connect.js';

CSIDConnect.init({ clientId: 'tu_client_id', mode: 'popup' });

// 1. Mostrar tarjeta flotante One-Tap si ya hay sesión
CSIDConnect.promptOneTap({
  onAuth: (res) => console.log('One-Tap exitoso:', res.user),
  onDismiss: () => console.log('Descartado por usuario')
});

// 2. Disparar inicio de sesión manual con botón personalizado
const auth = await CSIDConnect.signIn({ mode: 'popup' });

Integración Nativa en SwiftUI & ASWebAuthenticationSession

Utiliza ASWebAuthenticationSession y CryptoKit con soporte nativo para Universal Links (https://cokistudios.com/authorize) o esquemas personalizados (miapp://auth):

// 1. Iniciar sesión mediante CSIDManager en Swift
import SwiftUI
import AuthenticationServices
import CryptoKit

Task {
  do {
    let user = try await CSIDManager.shared.loginWithOAuthPKCE(
      clientId: "tu_client_id",
      redirectUri: "miapp://auth"
    )
    print("Bienvenido \(user.name) (\(user.email))")
  } catch {
    print("Error de autenticación: \(error)")
  }
}

Integración en Android (Kotlin) con CSIDKit

Usa Custom Tabs y PKCE respaldado por AndroidKeyStore (StrongBox/TEE) en Android 16 y 17:

// 1. Inicializar CSIDKit en Kotlin
val csid = CSIDClient.Builder(context)
  .setClientId("tu_client_id")
  .setRedirectUri("miapp://auth")
  .build()

// 2. Iniciar flujo de autorización segura
csid.launchAuth(activity) { result ->
  when (result) {
    is CSIDResult.Success -> {
      Log.d("CSID", "Conectado como: ${result.user.email}")
    }
    is CSIDResult.Error -> Log.e("CSID", result.message)
  }
}
