✨ Novedades en Looping Engine v2.6.0

? : & ??

Operadores ternarios y null-coalescing de evaluación perezosa para simplificar flujos condicionales.

match { }

Pattern matching estructural nativo con soporte para comodín default _.

0..=N & step N

Rangos inclusivos y pasos configurables con soporte completo para continue en bucles.

[a, b] & (x, y)

Destructuración nativa de listas y tuplas, y manejo robusto con try / catch / throw.

crypto.* & CSMS

Primitivas criptográficas: crypto.sha256, crypto.base64, crypto.uuid y crypto.csms_key.

Functional Stdlib

Procesamiento funcional de colecciones con pipeline (|>): map, filter, reduce, unique, zip, chunk.
