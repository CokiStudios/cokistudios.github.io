Inicio Rápido en Terminal

Instala las herramientas CLI oficiales (looping y smiledev) y valida el motor con la suite nativa incluida:

# macOS vía Homebrew
brew tap cokistudios/tap
brew install looping smiledev

# macOS / Linux vía instalador directo
curl -fsSL https://repo.cokistudios.com/engine/install.sh | bash

# Verificar entorno y ejecutar suite de pruebas C++17 (75/75)
smiledev doctor
looping test

Primer Juego 3D con .OBJ, C# y loopize++

Ejecuta escenas tridimensionales completas desde un archivo .loop o directamente en el REPL Web:

use "loopize++"
use "csharp"

define game3d "Starfleet Orbit" version 1.0:
    scene3d.world(name: "Orbit Sector 7", size: (220, 100, 220), sky: "nebula_void", fog: 0.007)
    camera3d.set(mode: "chase", pos: (0, 8.5, -16), target: (0, 2, 14), fov: 65, smooth: 0.14)

    cs! {
        public class PilotController : MonoBehaviour {
            public float Shield = 100.0f;
            public void Start() => LoopingBridge.Set("pilot_ready", true);
            public void Update(float dt) => Scene3D.Rotate("Starfighter01", 0.0f, dt * 40.0f, 0.0f);
        }
    }

    spawn3d.player("Starfighter01", at: (0, 2.2, 4), obj: "starfighter.obj", scale: 1.6, cs: "PilotController")
    spawn3d.obj("WarpGate", obj: "star_gate.obj", at: (0, 4.5, 42), scale: 2.0, color: "#c084fc")
    lz_wave_rush(1, "valkyrie", 4, 90, "valkyrie_drone.obj")
    lz_report()
