Looping Engine

El núcleo de alto rendimiento para el Ecosistema Coki Studios. Rendimiento bruto, latencia cero, control absoluto.

Arquitectura 3.0A

Nuestra arquitectura base optimizada para Apple Silicon y hardware nativo. Diseñada para sub-stepping de 120 FPS constantes mediante el aislamiento de memoria del motor.

Quick Start

Inicializa el motor en tu entorno:

import { LoopingEngine } from '@coki/looping';

const engine = new LoopingEngine({
    fps: 120,
    substepping: true
});

engine.start();
