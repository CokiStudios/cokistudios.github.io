Modo Quantum 3D, Modelos .OBJ, C# & loopize++

Proyección tridimensional inmersiva con carga nativa de modelos Wavefront .obj, Scripting C# (cs! y MonoBehaviour), raycasting Möller–Trumbore por triángulo y la librería híbrida loopize++ (ECS, oleadas, cámara spring-arm con sacudida, combos, tweens y misiones).

// Escena 3D con .OBJ, C# MonoBehaviour y loopize++
use "loopize++"
use "csharp"

scene3d.world(name: "Orbit Sector 7", size: (220, 100, 220), sky: "nebula_void")
spawn3d.obj("Starfighter01", obj: "assets/models/starfighter.obj", at: (0, 2.2, 6), scale: 1.5, color: "#38bdf8", cs: "StarfighterPilot")
val spawned = lz_wave_rush(1, "valkyrie", 3, 90, "valkyrie_drone.obj")
lz_hit_combo(250, 0.35)
lz_report()

Wavefront .OBJ & C# MonoBehaviour Interop

El motor nativo (75/75 pruebas C++17) y el runtime web cargan mallas .obj con obj3d.load / spawn3d.obj, normalización de escala, subdivisión, raycasting por triángulo y puente C# integrado (cs! { ... }, LoopingBridge.Get/Set, Scene3D, csharp.export).

cs! {
    public class OrbitalBossAI : MonoBehaviour {
        public float Shield = 180.0f;
        public void Start() => LoopingBridge.Set("cs_pilot_ready", true);
        public void Update(float dt) {
            Scene3D.Rotate("TitanFlagship", 0.0f, dt * 32.0f, 0.0f);
            Shield = Mathf.Clamp(Shield + dt * 4.0f, 0.0f, 200.0f);
        }
    }
}

Síntesis de Audio Web

El sistema de audio integrado genera efectos cristalinos sin cargar archivos externos de audio. Utiliza envolventes exponenciales y buffers de ruido blanco para saltos, dashes, impactos y recolección de coleccionables.

  • jump: Barrido de frecuencia sinusoidal ascendente.
  • double_jump: Triángulo con textura de ruido sintético.
  • dash: Sierra doble con decaimiento rápido.
  • coin: Acorde armónico de alta frecuencia (B5 - E6).

Colisiones y Partículas

Las colisiones AABB resuelven la profundidad y la velocidad en cada subpaso para evitar traspasos de geometría. El sistema de partículas emite ráfagas con gravedad configurable, decaimiento de opacidad y escala dinámica.

REPL & Pipeline Funcional

El entorno interactivo permite evaluar código en tiempo real con soporte para tuberías funcionales (|>), expresiones de coincidencia (match) y plantillas de interpolación avanzadas.

val score := 95
val tier := score >= 90 ? "SS" : "A"
