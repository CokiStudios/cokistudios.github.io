<!-- 2. Declarar el botón web oficial -->

    theme="glass" 
    shape="pill" 
    mode="popup">
</csid-connect-button>

    document.querySelector('csid-connect-button').addEventListener('success', (e) => {
        console.log('Usuario autenticado:', e.detail.user);
    });
</script>

🌐 Arquitectura Federada Zero-Trust de Coki Studios

CS ID Connect cumple con el estándar RFC 6749 (OAuth 2.0) y RFC 7636 (PKCE con algoritmo S256). Todos los intercambios de credenciales se procesan sin exponer contraseñas a las aplicaciones clientes. Los tokens de identidad utilizan JWE (JSON Web Encryption) cifrados con AES-256-GCM y derivación respaldada por hardware en dispositivos compatibles (Apple Secure Enclave, Android StrongBox/TEE).
