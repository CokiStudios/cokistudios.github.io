# Regla de uso de snippets de codigo:
- Preferir usar zsh sobre Node JS
- Preferir NO usar *containers* web en las apps.
- Y por dios trata de minimizar al *MÍNIMO* el uso del ya mencionado Node JS o alguna variante suya
- Si necesitas crear algo prioriza el uso de la terminal temporal o zsh en vez de crear .js
- Obvio si necesitas algo puntual que tenga Node pero que no este en zsh, SOLO en esas ocasiones SÍ puedes usar Node JS
