# Reglas de Sincronización de Forkar iOS

- **Destino del proyecto Xcode**: Cada vez que se realicen cambios, correcciones o novedades en el código de **Forkar iOS** (en `Forkar.iOS/`), se deben sincronizar/copiar los archivos actualizados hacia:
  `/Users/jerix/Documents/Xcode/Forkar/Forkar/Forkar/` (o `~/Documents/Xcode/Forkar/Forkar/Forkar/`).
- Mantener la integridad de los assets de Xcode (`Assets.xcassets`), el archivo de proyecto `.xcodeproj` y las extensiones ya configuradas en esa carpeta.
