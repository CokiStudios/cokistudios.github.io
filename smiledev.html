Guía Oficial: Cómo Crear Módulos SIN el CLI de smiledev

                        

                            El motor Looping en C++17 resuelve módulos directamente desde el sistema de archivos. No necesitas instalar ni ejecutar la terminal de `smiledev` para crear o consumir módulos locales.
                        

                    

                    100% C++ NATIVE RESOLVER
                


                
                

                    

                        

                            1
                            Crea la Carpeta
                        

                        

                            En tu proyecto, crea la carpeta modules/<nombre-modulo>/ en minúsculas y sin espacios.
                        

                    


                    

                        

                            2
                            Escribe smile.json
                        

                        

                            Crea el archivo de manifiesto indicando el nombre, versión, lenguaje y archivo de punto de entrada.
                        

                    


                    

                        

                            3
                            Programa el Código
                        

                        

                            Escribe tus funciones o clases en .loop, .hpp, .py o .js.
                        

                    


                    

                        

                            4
                            Importa con `use`
                        

                        

                            En tu script escribe use module "mi-modulo" y ejecuta con ./bin/looping.

¿Cómo busca Looping los módulos en el disco?

                    

                        El compilador e intérprete nativo C++ de Looping busca en este orden exacto sin requerir CLI ni red:
                    

                    
    
                        
  1. Módulo interno del Stdlib: Funciones en C++ nativo (math, crypto, csv, datetime, regex, sys).
    2. 
                        
  2. Manifiesto Local: Busca ./modules/<nombre>/smile.json y lee el campo entry_point.
    3. 
                        
  3. Fallback Local de Archivo: Si no hay smile.json, busca directamente ./modules/<nombre>/<nombre>.loop o ./modules/<nombre>/main.loop.
    4. 
                        
  4. Caché Global de Usuario: Busca en ~/.smiledev/modules/<nombre>/smile.json.
    5.
